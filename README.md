# Indian Hill ASP.NET container image source

Versions: 8.0.33, 9.0.22, 10.0.14. Tiers: Secure, Hardened and Validated.

Qualification covers the exact container images and retained image-level evidence. The OpenSSL provider is the identified cryptographic module; neither the container nor .NET is certified as a FIPS module. Customer hardware, operating environment, entropy and deployment qualification are outside this image delivery.
Validated reuses the qualified Hardened runtime/reference digests and adds independent cryptographic evidence.
